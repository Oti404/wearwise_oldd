# WearWise AI Engine

Acest modul se ocupă exclusiv de logica de Inteligență Artificială a sistemului WearWise (ex. predicții, recunoaștere imagini, generare texte conexe etc.). De regulă este un serviciu Python dedicat.

## Rulare Locală

1. Ai nevoie de instalarea dependențelor specifice AI.
2. În mod normal, vei folosi comanda:
   ```bash
   # Comenzi specifice de rulare (ex: python main.py sau activarea venv)
   ```

Alternativ, te folosești de scriptul central din root-ul monorepo-ului, ca să nu gestionezi manual variabilele de mediu:
```bash
../run.bat ai
```

Citește documentația centrală din repo-ul parinte dacă vrei să vezi arhitectura generală.
